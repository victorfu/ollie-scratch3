# 全部 28 個 SB3 版面檢查（2026-10-09）

這是對當時 28 個來源教材的歷史比對記錄。現在唯一正式範例庫是隨 Git 發布的 examples/web，舊來源目錄已移除。瀏覽器為本機 Chrome、CSS viewport 尺寸如下；未變更使用者瀏覽器的站點縮放設定。

尺寸：1920×1080、1440×900、1280×720、1024×640、900×640、1280×600。修正前後各檢查 28 × 6 = 168 組。

## 確認的差異與修正

1. 原本 iframe 未保留官方 Scratch playground 的 1024×640 最小工作區。在 900px 寬的外框內，舞台右緣仍位於 1015px，但 iframe viewport 只有 900px。父頁沒有統一的水平捲動外框。
2. 固定狀態列占 28px；1280×600 視窗只剩 572px 給 Scratch，角色面板高度被壓到 110px。原生 playground 會維持最小高度 640px。
3. 自製 iframe HTML 遺漏官方 playground 的全域 border-box 與 viewport meta；已補回。

修正：加上可捲動的 editor-viewport，iframe 最小 1024×640，不用 CSS transform 或 zoom 縮小整個 Scratch。1280×600 下，工作區現在高 640px、角色面板高 178px，可捲動到下方；900px 寬外框可水平捲動查看完整舞台。狀態列保留在外框外。

正常寬度保持官方舞台尺寸：1440／1280／1920px 為 480×360，1024px 工作區為 408×306；各組均為 4:3。積木預設縮放維持上游 0.675。沒有重新排列或縮放 SB3 的角色、積木或造型資產。
