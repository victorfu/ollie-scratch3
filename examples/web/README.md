# 網站範例庫

這 28 個 `.sb3` 是網站與部署使用的正式範例，隨 Git 一起發布。網站預設讀取此目錄，不需要額外來源資料夾或個人機器上的路徑。

第 28 課已包含無手追蹤防護，使用本專案提供的 `handpose2scratch_isHandDetected` 積木。其餘既有 opcodes、座標公式及第 10 號關節語意維持不變。

新增、更新或移除教材後：

```sh
npm run examples:index
npm test
```

一併提交 SB3 與 `manifest.json`。本機服務按「重新整理」即更新；部署環境需重新部署檔案。編輯器中修改後的作品只會下載到使用者端，不會覆寫這裡的教材。

`manifest.json` 只記錄檔名與 SHA-256，不包含本機來源路徑；它用於測試完整性，不限制 API 動態掃描。請保留作品及素材內既有的作者／授權標示，範例素材不自動套用程式碼的授權條款。
